# Mixy

A simple Android app for browsing and playing local media: music, images, videos, and PDFs. Built with Kotlin and Jetpack Compose.

Features:
- Music player with cover art and .lrc lyrics
- Image viewer with zoom and swipe
- Video player with gesture seek and speed control
- PDF viewer with scroll or page mode
- Folder browsing, search, and sort by name, date, size
- Exclude folders you don't want to see

Build:

`./gradlew assembleDebug`

No ads, no online content. No data collection.

# Mixy

一个简单的 Android 应用，用来浏览和播放本地媒体：音乐、图片、视频和 PDF。使用 Kotlin 和 Jetpack Compose 开发。

功能：
- 音乐播放，支持封面和 .lrc 歌词
- 图片查看，支持缩放和滑动
- 视频播放，支持手势快进和倍速
- PDF 阅读，支持滚动或翻页
- 浏览文件夹、搜索、按名称、日期、大小排序
- 屏蔽不想看到的文件夹

构建：

`./gradlew assembleDebug`

无广告，无在线内容，不收集任何数据。
